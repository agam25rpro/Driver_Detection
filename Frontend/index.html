The Problem

Why Distracted Driving Matters

Distracted driving is one of the leading causes of road accidents worldwide. This project uses AI to automatically detect unsafe driver behavior in real time.

Dataset

State Farm Distracted Driver Detection (Kaggle). Over 26,000 labeled dashboard camera images across 10 behavior categories from multiple real drivers.

Model

EfficientNetB3 pre-trained on ImageNet as a feature backbone, with a custom classification head trained via a two-stage fine-tuning strategy.

Generalization

Training and validation sets are split at the driver identity level — the model is tested on entirely unseen individuals, ensuring real-world reliability.

Risk Scoring

Each class carries a severity weight. The model outputs both a behavior class and a quantitative risk score, enabling per-driver safety profiling.

Architecture

How the Model Works

A carefully designed pipeline from raw images to actionable safety classifications.

01

Data Ingestion

Raw 640×480 dashboard images are loaded alongside CSV metadata. Each image is associated with a driver ID and behavior class.

→
02

Driver-Level Split

Instead of random splitting, the 80/20 train-validation split is done at the subject level. No driver's images appear in both sets — preventing data leakage.

→
03

Augmentation

Real-time augmentation via Keras ImageDataGenerator: ±15° rotation, 10% width/height shift, 10% zoom, horizontal flip. Images resized to 300×300.

→
04

EfficientNetB3 Backbone

ImageNet pre-trained weights give the model strong low-level feature extraction (edges, textures). The backbone is frozen in Stage 1, then unfrozen in Stage 2.

→
05

Custom Head

GlobalAveragePooling2D → Dropout(0.4) → Dense(10, softmax). Dropout regularizes the model; softmax outputs a 10-class probability distribution.

→
06

Two-Stage Training

Stage 1: Head only, lr = 1e-3. Stage 2: Full network unfrozen, lr = 1e-5. EarlyStopping + ModelCheckpoint callbacks prevent over-fitting.
